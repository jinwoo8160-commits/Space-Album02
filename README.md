# 시공간 앨범 — 지도

사진의 시간과 공간을 Mapbox 위에 두 단계로 보여 줍니다. 국가~구 줌은 육지 도트 격자, 동·거리 줌은 흰 모노톤 상세 지도와 사진 핀입니다.

## 실행

```bash
cp .env.example .env.local
# .env.local 에 Mapbox 토큰을 넣습니다.
npm install
npm run dev
```

[http://127.0.0.1:43123](http://127.0.0.1:43123)

토큰은 [Mapbox 계정](https://account.mapbox.com/access-tokens/)에서 발급하고 `NEXT_PUBLIC_MAPBOX_TOKEN` 으로 등록합니다. 코드는 `process.env.NEXT_PUBLIC_MAPBOX_TOKEN` 만 읽습니다.

## 줌 (연속)

휠 · 트랙패드 · 핀치 · 왼쪽 +/- 버튼이 Mapbox 연속 줌입니다. 움직이는 동안에는 레이어를 다시 계산하지 않고, **줌 9.5를 넘고 손을 뗐을 때만** `visibility` 를 한 번 바꿉니다.

`minZoom` 은 **5.4** 입니다. 줌이 6.0 아래로 내려가면 카메라가 남한 정중앙 `[127.8, 35.8]` 으로 자석처럼 끌리고, 5.4에 닿으면 그 좌표에 고정됩니다.

| 줌 | 레이어 |
| --- | --- |
| **5.4 ~ 9.5** | 육지 도트. 사진 1장당 가우시안으로 점수를 퍼뜨린 뒤 4분위 `densityLevel` 로 진하기를 나눕니다. 카테고리 핀을 고르면 그 사진만으로 밀도를 다시 계산하고, 도트 색은 키컬러(여러 색이 겹치면 가중치 RGB 혼합)입니다. 줌 중에는 재계산하지 않습니다. |
| **9.5+** | 도트 `visibility: none` + 흰 모노톤 수역/도로/건물/라벨 + 묶음·개별 핀 |

위성 타일은 쓰지 않습니다. 상세 지도도 같은 흰 스타일 안에서만 켭니다.

오른쪽 키컬러 핀의 **+** 로 카테고리를 추가하고, 핀을 **길게 누르거나 우클릭**하면 삭제합니다. 사진 상세의 **+** 도 같은 추가 창을 열고, 만든 색은 그 사진에 바로 지정됩니다. 검은색은 키컬러가 아닙니다. 카테고리가 없는 사진은 기본 도트(opacity 0.1)로만 보입니다.

국가 선택 창의 세계·대한민국·일본·중국·미국 미니 지도도 같은 흰 Mapbox 바탕 위에 영토 도트 격자를 올립니다. 세계지도는 잠금·클릭 없이 프리뷰만 보여 주고, 지금은 **대한민국만** 고를 수 있습니다. 일본·중국·미국 카드는 잠겨 있습니다.

## 하단 탭

| 탭 | 화면 |
| --- | --- |
| **지도** | Mapbox 도트 지도 |
| **앨범** | 년/월/주/일 기간 선택, 남한 미니 지도, 5열 사진 그리드. 썸네일을 누르면 상세가 열리고, 왼쪽 아래 키컬러 점을 누르면 그 장소의 위성 전경이 미니 지도를 덮습니다. 같은 점을 다시 누르면 남한 도트 지도로 돌아갑니다. |
| **기록** | 하루 동선 타임라인. 제목·부제·코스(장소+사진, 최대 5개)를 남기고, 롱프레스로 편집·정렬합니다. 사진 위젯은 앨범 선택 창과 연결됩니다. |
| **설정** | 지도 테마·스냅 줌·중심점, 데이터/보안 UI, 앱 정보 |

설정에서 **라이트/다크**를 고르면 같은 Mapbox 스타일 안에서 색만 바뀝니다. 스냅 줌(3.0~20.0, 기본 5.4)과 고정점 경도/위도(기본 127.8, 35.8)는 지도 탭의 minZoom·자석 정렬에 바로 붙습니다.

테스트용 사진은 대한민국 500장입니다. 수도권·강원·충청·전라·경상·제주 50개 거점에 10장씩 흩어지고, 촬영일은 2024년 1월부터 2026년 9월까지 고릅니다. 키컬러(분홍·초록·시안·빨강)는 장마다 다르게 붙어 앨범 그리드 점과 미니 지도 점에 같이 쓰입니다. 해외 3장과 위치 미지정 3장은 국가 잠금·설정 EXIF 목록용으로 따로 있습니다.
