# 시공간 앨범 — 지도 1차 구현

사진이 **언제·어디서** 찍혔는지를 한 화면에서 보는 웹 앱입니다.  
React Native 대신 **Next.js + TypeScript + Tailwind + shadcn/ui** 로 만들었습니다. 브라우저에서 바로 미리 볼 수 있고, 컴포넌트 구조는 나중에 React Native로 옮기기 쉽게 화면 단위로 나눠 두었습니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 [http://127.0.0.1:43123](http://127.0.0.1:43123) 을 엽니다.

## 화면 구성

| 탭 | 경로 | 상태 |
| --- | --- | --- |
| 지도 | `/` | 4단계 줌 + 필터 + 타임피커 |
| 기록 | `/records` | 빈 페이지 (2차 구현용) |
| 설정 | `/settings` | 빈 페이지 (2차 구현용) |

## 지도가 동작하는 방식 (데이터 흐름)

```
MOCK_PHOTOS  ──►  photos state (색만 수정 가능)
                      │
                      ▼
         국가 / 연·월·일 / 컬러핀 필터
                      │
                      ▼
               filteredPhotos
                 │         │
                 ▼         ▼
          국가·시/도      구/시·동
           DotMap        StreetMap
        (점 명암)     (묶음 / 개별 핀)
```

핵심 파일:

- `src/context/map-context.tsx` — 지도 화면의 상태(줌, 필터, 선택 사진)
- `src/lib/filters.ts` — 국가·날짜·색 거르기
- `src/lib/clustering.ts` — 줌에 따른 묶음 단위
- `src/components/map/` — 버튼, 도트맵, 스트리트맵, 팝업, 타임피커

## 줌 4단계

1. **국가** — 나라를 점(dot)으로 그리고, 근처 사진 수로 점을 진하게
2. **시/도** — 행정구역 경계 칸을 비워 간격을 만들고 명암은 동일
3. **구/시** — 미니멀 도로 지도 + 사진 묶음(스택)과 숫자
4. **동/군/구** — 같은 좌표만 묶고, 사진을 누르면 상세 팝업

`+` / `-` 버튼, 마우스 휠, 점·묶음 클릭으로 단계를 오갑니다.
